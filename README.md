# 🏗️ Chandimata Hardware Shop Website

A modern and responsive **Hardware Shop Website** developed using **Python (Django)** to help customers explore construction materials and hardware products online. The website provides detailed product information, categorized product listings, contact details, and an easy-to-manage admin panel for updating inventory.

This project was developed for my father's hardware business to establish an online presence and improve product accessibility for customers.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Soumya-CSE/Hazra-Hardware-Shop.git
```

### Navigate to Project

```bash
cd Hazra-Hardware-Shop
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py migrate
```

### Run the Server

```bash
python manage.py runserver
```

Visit:

```
http://127.0.0.1:8000/
```
